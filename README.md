# Studio AS Agenda

Projeto de agendamento do Studio AS com formulário em HTML/JavaScript para facilitar a seleção de serviço, data, horário e envio da solicitação via WhatsApp.

## Funcionalidades

- Seleção de serviços e preços
- Escolha de dia e horário disponível
- Cadastro de nome e WhatsApp
- Geração de mensagem pronta para envio
- Copiar mensagem para área de transferência
- Design em preto e dourado, com visual premium

## Como usar

1. Abra o arquivo index.html no navegador.
2. Escolha o serviço desejado.
3. Selecione o dia e o horário disponível.
4. Preencha nome e WhatsApp.
5. Clique em solicitar agendamento.
6. Copie ou envie a mensagem pelo WhatsApp.

## Estrutura do projeto

- index.html — página principal do agendamento
- README.md — documentação do projeto

## Observação

O número de WhatsApp do Studio AS deve ser configurado no campo WHATSAPP dentro do arquivo HTML antes de enviar a mensagem diretamente.
